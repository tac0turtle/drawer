# Drawer

A lightweight macOS menu bar manager that hides and shows status bar icons. Spiritual successor to [Dozer](https://github.com/Mortennn/Dozer), rebuilt with Swift 6, SwiftUI, and zero dependencies.

## Build

Requires Xcode 16+ and [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```sh
brew install xcodegen
make build    # Debug build
make test     # Run tests
make lint     # SwiftLint --strict
```
